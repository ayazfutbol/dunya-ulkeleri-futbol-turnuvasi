V10 - Tam Oyun Kod Editörü

Yönetim Paneli > Tam Oyun Kod Editörü bölümünde oyunun tamamını değiştirebilirsin.
Editör <!DOCTYPE html> ile başlayıp </html> ile biten tam HTML kaynağını kabul eder.
CSS ve JavaScript de aynı dosyanın içindedir.

Yayınlama:
1) Oyunu bakım moduna al.
2) Mevcut Tüm Kodu Getir.
3) HTML/CSS/JS kodunu değiştir.
4) Kod Yapısını Kontrol Et.
5) Tam Kodu Kaydet ve Yayınla.
6) Oyunu Aç.

Tam dosya Firebase Storage'a yüklenir. Firestore'da sadece sürüm ve dosya URL'si tutulur.
Oyuncular giriş yaptığında yayınlanan tam HTML sürümüne yönlendirilir.

Firebase Console:
- Storage Rules bölümüne storage.rules içeriğini Publish et.
- Firestore Rules önceki firestore.rules olarak kalabilir.
