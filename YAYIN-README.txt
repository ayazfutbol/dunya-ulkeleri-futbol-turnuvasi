DÜNYA ÜLKELERİ FUTBOL TURNUVASI - TAM GÜNCEL YAYIN PAKETİ

Bu klasör GitHub Pages'e doğrudan yüklenmek üzere hazırlanmıştır.

Dosyalar:
- index.html: güncellenmiş ana site
- .nojekyll: GitHub Pages için
- sitemap.xml: site haritası
- YAYIN-README.txt: yayın notları

Güncellemeler:
- Şampiyon olunca şampiyonluk paneline geçiş düzeltildi.
- Şampiyonluk kaydı eklendi.
- Oyun durumu ücretsiz olarak tarayıcıya kaydediliyor.
- Sayfa yenilendiğinde seçilen ülke korunuyor.
- Ücretli Firebase Storage gerektiren kayıt yapısı kullanılmıyor.

GitHub'a yüklerken bu klasörün İÇİNDEKİ dosyaları deponun ana dizinine yükle.
