DUNYA ÜLKELERİ FUTBOL TURNUVASI - TAMAMEN ÜCRETSİZ YAYIN SÜRÜMÜ

Bu sürüm Firebase Storage kullanmaz.

Kullanılanlar:
- GitHub Pages: siteyi yayınlamak için
- Firebase Authentication: Google ile giriş
- Cloud Firestore: kullanıcılar, yöneticiler, engelleme, bakım modu, takım güçleri ve yayınlanan oyun kodu

ÖNEMLİ:
- Firebase projesi Spark planında kalmalıdır.
- Blaze / kart / faturalandırma gerekmez.
- Yönetim panelindeki HTML + CSS + JavaScript "Kodu Kaydet ve Yayınla" özelliği korunmuştur.
- Büyük tam HTML kodu Firestore belge sınırına takılmaması için gameCodeChunks koleksiyonunda parçalara ayrılır.
- Yayınlanan sürüm oyuncunun tarayıcısında Firestore'dan parçalar birleştirilerek açılır.

Firebase Console'da Firestore Rules bölümüne firestore.rules içeriği uygulanmalıdır.
GitHub Pages'de index.html ve firebase-config.js kök dizinde bulunmalıdır.
