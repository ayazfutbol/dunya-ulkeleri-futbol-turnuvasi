DÜNYA ÜLKELERİ FUTBOL TURNUVASI - GÜNCEL ÜCRETSİZ SÜRÜM

Bu klasör GitHub Pages için hazırlanmıştır.

Dosyalar:
- index.html: ana oyun + şampiyonluk ekranı + Yönetim Paneli butonu
- admin.html: ayrı yönetim paneli

ÖNEMLİ:
Bu ücretsiz sürümde GitHub Pages backend sağlamadığı için istatistikler kullanıcı cihazının localStorage alanında tutulur. Tüm ziyaretçiler için ortak gerçek istatistik ve güvenli admin yetkisi istenirse Firebase/başka backend gerekir.

GitHub'a yükleme:
1) Repository'nin ana sayfasına gir.
2) Eski index.html'i sil.
3) Bu klasördeki index.html ve admin.html dosyalarını repository'nin KÖKÜNE yükle.
4) Commit changes.
5) Actions > pages build and deployment yeşil tik olunca site güncellenir.
